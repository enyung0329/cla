旺旺旅平險 PWA v22.3（此說明取代舊版 README-v22.txt）

更新網站：將所有檔案及 vendor 資料夾，上傳到原本 index.html 所在位置並覆蓋。
vendor 檔名與目錄結構請保持原樣，不要解壓縮 .gz 檔案。
部署完成後按「強制刷新」，確認版本為 v22.3。
首次請連網保持頁面開啟，完成元件快取後可離線使用。須使用 HTTPS 或 localhost。

貼上文字後按「辨識文字並帶入」。支援國家、中文／數字人數及獨立兩行去回程航班。
例：日本／五個人／BR124／BR125，帶入日本、5人、去程BR124、回程BR125。
無旅客資料時仍帶入旅遊資料並保留原名冊。有明確人數時以該人數為準，請核對名冊完整性。

圖片與 PDF：選擇檔案後按「辨識檔案並帶入」。可多選，每個檔案最多30 MB。
支援 JPG、PNG、WebP、BMP、GIF 與 PDF，HEIC 請先轉成 JPG。
PDF 優先擷取文字，無足夠文字的頁面改用圖片辨識；有少量頁首文字的掃描頁可能需另存圖片辨識。
加密 PDF 請先解除密碼。辨識文字附加至文字區並帶入欄位，檔案不會上傳到外部服務。
首次辨識可能需數十秒；文字、姓名、證號及生日均須人工核對。

保留 v21 全部費率及原有報價、列印、投保與 PWA 功能。
實際 Chrome 測試通過：旅遊地點／人數／姓名／航班，斷網 PNG OCR、文字 PDF、掃描 PDF、離線重新開啟。
原有名冊、年齡計算、通報格式及費率試算測試通過，33,424筆費率與v21逐字相同。
圖片辨識測試仍有中文姓名誤字，請逐項核對。

第三方元件及來源請見 vendor/SOURCES.txt 與授權文件。
